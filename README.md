# A11y-Audit-Report

Python script is created to genarate Accessibility Audit Report in HTML format as well as MS Word Format.

# Steps
1. Log all the issues in a file name issues.csv
2. Add the issues.csv file at the root directory of this repository.


# Install Python Packages
1. pip3 install pandas requests python-docx

# Run script
1. python3 generate_html_report.py
2. python3 generate_word_document.py
